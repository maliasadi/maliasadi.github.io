# Ali Asadi

Personal site and blog. [Astro](https://astro.build) builds a static site from Markdown posts and HTML slide decks.

## Preview locally

Install Node.js 22 or newer, then from this folder:

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

To check the production build:

```bash
npm run build
npm run preview
```
